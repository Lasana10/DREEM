# DREEM Personalization Model

## Purpose

DREEM should not be a static portal. It should evolve around each user and get more useful over time.

The system should personalize by:

- role
- class or department
- age group
- responsibilities
- timing
- recent activity
- performance patterns
- school events

## Student Personalization

Students should get a dashboard shaped around learning and daily action.

### Personalized elements

- today's timetable
- pending assignments
- missed work
- notes from teachers
- revision materials
- subject weak points
- recognition badges
- attendance reminders

### Evolving services

As the system learns the student's pattern, it can improve:

- which resources are shown first
- what revision help is suggested
- when reminders are sent
- which support prompts appear
- what parent follow-up is generated

## Teacher Personalization

Teachers should get a dashboard shaped around teaching load and class needs.

### Personalized elements

- today's classes
- pending attendance
- pending grading
- students needing intervention
- pacing alerts
- class comparison
- lesson follow-up prompts
- resource suggestions

### Evolving services

As DREEM observes real usage and class outcomes, it can improve:

- suggested lesson materials
- intervention recommendations
- pacing advice
- comment bank suggestions
- workload summaries
- professional growth resources

## Parent Personalization

Parents should get a calm, simple, high-trust experience.

### Personalized elements

- child attendance summary
- assignment reminders
- progress summary
- transport alerts
- fee status
- home follow-up material
- school announcements relevant to their child

### Evolving services

The system can improve:

- timing of alerts
- clarity of summaries
- language simplification
- recommended follow-up actions at home

## Leadership Personalization

Leadership should see what most needs attention now.

### Personalized elements

- fee health
- academic risk
- staff issues
- incidents
- transport disruptions
- system alerts
- school-wide announcements

### Evolving services

DREEM can improve by:

- prioritizing unusual signals
- highlighting worsening trends
- surfacing recurring bottlenecks
- summarizing the school day automatically

## Finance Personalization

Finance users should get a view centered on control and follow-up.

### Personalized elements

- overdue fees
- today's payments
- exceptions
- receipts requiring action
- expected cash flow
- follow-up queues

### Evolving services

DREEM can improve by:

- prioritizing high-risk debt
- scheduling reminder workflows
- flagging payment anomalies
- showing likely collection outcomes

## Transport Personalization

Transport teams should get context for the exact route and trip they manage.

### Personalized elements

- route list
- student boarding list
- delay alerts
- stop sequence
- parent communication prompts

### Evolving services

DREEM can improve by:

- surfacing recurring delay routes
- warning of absence patterns
- improving pickup communication

## Personalization Rules

DREEM should personalize responsibly.

It should:

- help users act faster
- stay clear and not manipulative
- explain important AI suggestions
- allow admins to configure notification intensity
- keep sensitive actions under human control
