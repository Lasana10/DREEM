# DREEM Stack Recommendation

## Frontend

- React
- TypeScript
- Vite
- Tailwind CSS

## Backend

Recommended primary backend:

- Supabase

Why:

- Postgres database
- authentication
- storage
- realtime
- edge functions
- fast early delivery

## Online Deployment

Recommended public hosting:

- Cloudflare Pages

Optional later edge layer:

- Cloudflare Workers

## Database

- PostgreSQL through Supabase for cloud data
- local PostgreSQL or SQLite for school node deployments

## Mobile

- React Native with Expo

## Notifications

- Firebase Cloud Messaging for Android push
- email provider for parent and staff notices
- optional WhatsApp or SMS integration later

## File Storage

- Supabase Storage for cloud-accessible files
- local disk for school-node sensitive files

## Local Services

- Node.js API service
- sync service
- hardware sentinel service

## AI Layer

- local lightweight AI optional on school node
- cloud model access for summaries and advanced analysis

## Why This Stack Works

It gives:

- a good free/low-cost starting point
- strong developer speed
- a clean path from pilot to serious deployment
- hybrid support for online and local modes
- strong public delivery through Cloudflare
